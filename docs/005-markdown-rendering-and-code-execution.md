# Markdown 渲染与代码执行

## 1. 功能范围

Markdown 渲染器同时服务编辑器预览和公开分享阅读。它基于 ReactMarkdown，扩展 GFM、数学公式、目录、内部链接、提示块、媒体、代码高亮、Mermaid 和可运行代码。渲染器处理的是用户输入，因此 HTML、样式、链接和代码执行必须有明确安全边界。

## 2. 渲染管线

正文进入 ReactMarkdown 前先进行受控预处理：

- 转换 `[[文档]]` 等内部链接语法。
- 识别 `[toc]` 或 `[TOC]` 占位。
- 处理提示块和软换行兼容规则。
- 修正部分列表连续行，使编辑预览符合用户输入直觉。
- 对不在允许范围内的原始结构进行转义或限制。

随后依次启用 GFM、数学公式和受控的原始 HTML 支持，并由自定义组件渲染标题、链接、代码、图片、视频、音频和样式节点。

预处理顺序是语法契约。改变顺序可能让代码块内文本被误当成目录、链接或提示块。

## 3. 标题与目录

- 标题生成稳定 slug，用作页面锚点和目录定位。
- 重复标题必须生成不冲突的锚点。
- 目录占位只在正文显式出现 `[toc]` 时插入目录；编辑器浮动目录可以独立读取标题树。
- 标题层级应保留原始 Markdown 语义，不能为了视觉样式改变 HTML heading 等级。

修改 slug 算法会破坏已分享链接中的锚点，应保持向后兼容或提供兼容映射。

## 4. 内部文档链接

内部链接最终渲染为 `/docs/{id}` 或系统认可的文档路径。编辑器内可显示悬停预览；公开分享页面不能借此绕过鉴权读取私有文档。公开页面遇到私有内部链接时只能展示普通链接或登录后再鉴权访问。

链接提取器和渲染器必须认可相同路径格式，否则 UI 看似可点击但反向链接数据不会更新。

## 5. 原始 HTML 与样式

渲染器允许有限原始 HTML 以支持常见 Markdown 扩展，但必须限制危险内容：

- 不执行 `<script>`、事件处理属性或 `javascript:` URL。
- 只允许明确支持的 `span` 样式属性和值。
- 外部链接使用安全的跳转属性。
- 图片和媒体 URL 不应注入任意 DOM 属性。

新增 HTML 能力时先扩展允许列表，不得直接放开全部标签和属性。

## 6. 代码块

代码块解析语言和可选文件名元信息，提供：

- 语法高亮。
- 一键复制。
- 文件名或语言标识。
- Mermaid 专用渲染。
- 带 `[runnable]` 标记时的运行按钮、输出和错误展示。

代码块元信息解析必须容忍未知语言；未知语言仍应显示纯文本，不能导致整篇文档渲染失败。

## 7. Mermaid

Mermaid 代码在客户端渲染，错误显示为局部错误状态。图表支持放大查看、缩放、拖动和调试信息。

- Mermaid 初始化配置必须避免执行任意 HTML。
- 每个图表使用独立且稳定的 DOM 标识。
- 渲染失败只影响当前代码块。
- 弹窗关闭后清理缩放和拖动监听器。

## 8. 媒体

图片 alt 前缀可显式表示图片、视频或音频，上传流程也按 MIME 类型生成相应 Markdown。渲染器按最终 URL 加载资源：

- 图片使用受控 `img` 属性。
- 视频和音频使用浏览器原生 controls。
- 普通文件保持下载链接。
- 加载失败应显示替代文本，不应让页面布局永久阻塞。

## 9. 可运行代码

带运行标记的代码在浏览器 Worker 中执行。当前支持 JavaScript、Python、Go、Lua 和 C：

- JavaScript 使用 Worker 内求值。
- Python 通过 Pyodide 运行时加载。
- Go 使用浏览器端解释/运行时及对应 WASM 支持文件。
- Lua 使用 Fengari。
- C 使用 JSCPP。

运行时按语言懒加载并复用 Worker，避免每个代码块重复下载大型依赖。一次运行只绑定当前调用的输出监听器，结果按请求归属回到正确代码块。

第三方运行时可能从 CDN 下载，离线或受限网络下应显示局部错误。代码执行不属于可信服务端执行，但 Worker 仍可能访问浏览器允许的网络能力；公开分享中运行不可信代码必须由用户主动点击，不可自动执行。

## 10. 执行资源约束

当前运行模型依赖浏览器 Worker。维护时必须确保：

- 每次运行有可取消或超时策略，避免死循环长期占用 CPU。
- 页面卸载后终止不再使用的 Worker 和监听器。
- 输出大小有上限，避免大量日志耗尽内存。
- 同一语言的并发请求具备请求 ID，不能串行监听器错配。
- CDN 加载失败和语言不支持返回明确错误。

若运行时复用策略无法满足隔离，应优先终止并重建 Worker，而不是让旧状态污染后续执行。

## 11. 不可破坏的约束

- 编辑器预览与公开分享必须使用一致的 Markdown 语义和安全策略。
- 预处理不能改写 fenced code block 内的普通文本。
- 用户 HTML 和 URL 不能注入脚本、事件或危险协议。
- Mermaid 或代码运行失败必须局部降级。
- 可运行代码只能由用户显式触发，不得在文档打开时自动执行。
- 内部链接的渲染格式必须与后端关系提取格式一致。
- 大型运行时只能按需加载，基础 Markdown 阅读不能依赖它们成功。

## 12. 验证要点

- GFM、公式、目录、重复标题、提示块和内部链接正确渲染。
- 代码块内的 `[toc]`、`[[...]]` 和 HTML 保持代码文本。
- 危险标签、属性和 URL 不能执行。
- Mermaid 成功、语法错误和多图并存场景互不影响。
- 每种运行语言在成功、初始化失败、运行错误和长时间执行时有明确状态。
- 编辑预览和公开分享对同一 Markdown 产生一致结果。
