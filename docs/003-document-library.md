# 文档库页面

## 1. 功能范围

`/docs` 是登录后的主页面，负责浏览、搜索、筛选和创建文档，并提供导入、导出、置顶、收藏、分享列表和主导航入口。页面聚合多个接口，但文档列表仍以服务端分页和用户范围查询为事实源。

## 2. 页面布局

桌面页面由侧栏、顶部操作区和内容列表组成：

- `>=1024px` 的侧栏提供 All Notes、Starred、Shared、Tasks、Templates、Assets、Tags、
  Settings、Recent 和标签筛选。
- 顶部区域提供可伸缩搜索、标签 Combobox、新建和用户菜单；导入、导出和账户操作位于支持
  键盘的统一 Menu。
- 主区域展示文档卡片、加载状态、空状态和分页触底加载。

小于 `1024px` 时不渲染常驻侧栏，顶部显示应用导航按钮。Drawer 提供与桌面一致的主导航，
最多显示有限 Recent 和 Tags，并提供 Manage all。移动顶栏只保留导航、宽度不小于
`120px` 的搜索、新建和用户菜单；Assets 不占用顶栏。选择导航或筛选后 Drawer 关闭并恢复
焦点。移动端和桌面端共享数据状态，响应式变化不能触发重复创建或丢失筛选条件。

## 3. 文档列表

普通列表通过文档查询接口获取：

- 默认按置顶状态和创建时间排序。
- 请求包含分页参数和是否包含标签。
- 返回文档记录、分页总量以及页面展示所需的标签、收藏和置顶状态；文档对象不包含独立内容摘要。
- 页面以固定批次追加数据，切换查询条件时清空旧游标并重新加载。
- 卡片主体使用文档 Link，Star、Pin 和复制分享链接是同级 Button，不能嵌套在主链接内。
- 卡片显示标题、最多两行正文摘录、更新时间和标签；正文摘录直接从 `content` 生成，去除 Markdown 标记并
  限制长度。

侧栏的最近文档和主列表是不同视图。最近文档用于快速跳转，不应覆盖主列表分页状态。

## 4. 搜索与筛选

### 4.1 普通搜索

普通搜索由后端在当前用户文档范围内匹配标题和正文。搜索词、标签、收藏等条件改变时应从第一页重新请求。快速输入产生的旧响应不能覆盖新查询结果。

### 4.2 标签搜索

输入以 `/` 开始时，页面切换为标签选择体验。选中标签后，列表按标签 ID 过滤。标签显示名只用于 UI，后端筛选必须使用当前用户拥有的标签标识。

标签查询固定短防抖并取消旧请求。Combobox 通过 listbox/option 语义暴露活动项，支持方向键、
Home、End、Enter 和 Escape；清空搜索是显式可见的操作。

### 4.3 收藏视图

收藏视图只展示 `starred` 文档。收藏切换采用即时 UI 反馈，但请求失败时必须回滚；切换视图后仍以服务端结果校准。

### 4.4 已分享视图

分享视图读取当前用户有效分享列表，并展示复制公开链接等操作。列表接口通过
`content_preview` 返回正文前 1000 个字符，前端再按普通卡片规则生成摘录；它不是普通文档分页结果的
本地过滤，过期或撤销的分享由后端排除。

### 4.5 语义搜索

语义搜索调用 Embedding 检索接口 `/api/v1/ai/search` 并以匹配片段卡片呈现。该路径为已发布兼容
契约，内部只生成查询向量，不调用文本生成模型。它不替换普通列表，也不改变文档主列表的分页游标。
Embedding 未配置或搜索失败时，普通搜索和文档浏览必须保持可用。

## 5. 新建文档

新建按钮执行一次文档创建请求，初始标题为 `Untitled`，成功后跳转 `/docs/{id}`。前端在请求进行中禁用重复提交。后端负责创建初始文档状态和版本数据，不得由前端预造 ID。

## 6. 置顶与收藏

置顶、取消置顶、收藏和取消收藏均调用独立接口：

- UI 可先更新当前卡片状态。
- 失败时恢复之前状态并提示。
- 置顶变化会影响排序；必要时重新加载，不能只改变图标却保留错误顺序。
- 操作必须受后端用户归属校验。

## 7. 标签侧栏

标签侧栏分页加载当前用户标签，支持置顶标签和按标签进入文档筛选。标签置顶是标签自身属性，不等同于文档置顶。标签被删除后，页面需移除对应筛选并重新请求列表。

## 8. 导入与导出入口

导入弹窗负责上传、预览、选择冲突策略、确认和轮询进度；导出入口下载服务端生成的数据。页面只协调流程，解析和持久化规则由后端控制。离开页面后应停止无意义轮询，但已经确认的后台导入任务继续在服务端执行。

## 9. 状态与竞态约束

- 列表请求必须区分“首次加载”“追加加载”和“查询条件改变”。
- 搜索、标签和视图切换时，旧响应不得追加到新结果。
- 首次请求失败显示页内 Error 和 Retry；追加失败保留已有卡片并显示 inline Retry；失败不能
  显示成空列表。
- All、Starred、Shared、Tag 和 Search 分别有明确空状态与 Clear/New 操作。
- 新建、置顶、收藏、复制分享链接和导入确认需要明确 loading 或 disabled 状态。
- 前端的统计数字和卡片状态在变更后应通过接口结果校准。
- 文档删除或权限变化后，旧卡片不能继续作为可访问事实源。
- 所有文档、标签和分享查询必须在后端按用户隔离。
- 页面级 `h1` 和浏览器标题随 All notes、Starred notes、Shared notes 或标签筛选变化。
- 页面使用 `h-dvh`，从最窄手机到宽桌面都不得产生 body 横向滚动。

## 10. 验证要点

- 空账号、少量文档和多页文档均正确展示。
- 普通搜索、标签筛选、收藏和分享视图相互切换时没有串数据。
- 快速输入搜索词和快速切换筛选不会出现旧结果覆盖。
- 新建请求重复点击只创建一个文档。
- 置顶、收藏失败能回滚，成功后排序和统计一致。
- Embedding 不可用时页面仍能使用普通搜索和全部文档功能。
- 导入任务离开页面后不丢失服务端状态，返回后可按任务状态继续确认结果。
- 手机和平板可以从 Drawer 进入全部应用导航、Recent 和 Tags；仅用键盘可以打开、选择、
  Escape 关闭并恢复焦点。
- 文档卡片主链接、Star、Pin 和分享复制拥有独立焦点，触摸端不依赖 hover。
